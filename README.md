# Ultima Skate

## Install

1. Download **[UltimaSkate-Setup.zip](https://github.com/CyberZombie01/UltimaSkate-Releases/releases/download/game/UltimaSkate-Setup.zip)**.
2. **Before unzipping it:** right-click the zip > **Properties** > tick **Unblock** (bottom of the General tab) > **OK**.
   Without this, Windows' Smart App Control blocks "Play Ultima Skate" because it came from the internet.
   (Already unzipped it? Delete the folder, unblock the zip, and unzip it again.)
3. Unzip it anywhere (e.g. Documents\Ultima Skate) and double-click **Play Ultima Skate**. The first time it
   downloads the game (about 4 GB); after that only what changed.

If SmartScreen warns about a file: **More info > Run anyway**.

---
The launcher downloads the game from the release tagged `game` (manifest.json and its packs), published by
Tools/Release/make_release.ps1 in the project.
